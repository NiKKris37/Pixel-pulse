# Pixel Pulse

Tableau de bord néon pour Pixel 7 (batterie, stockage, réseau, raccourcis vers les réglages).

## Installer l'application

Quand la compilation est terminée (onglet **Actions**), ouvre la page **Releases**
sur le téléphone, télécharge `pixel-pulse.apk` et ouvre-le.

## Fonctions

- Tableau de bord batterie, stockage, réseau et raccourcis vers les réglages
- Grand ménage : les photos et vidéos les plus lourdes, supprimées après confirmation
- Quatre jeux de couleurs néon, icône et écran de démarrage, retours par vibration

Chaque compilation essaie d'abord l'application sur un émulateur Android.
